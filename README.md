# 💫 About Me:
Cybersecurity Analyst with 3+ years of enterprise SecOps experience in London's financial sector. I've spent those years doing the unglamorous-but-critical work that keeps organisations secure — triaging alerts, chasing down vulnerabilities, automating the repetitive so analysts can focus on what actually needs a human brain.<br><br>At Quod Orbis, I built Python-based incident response automation that cut response latency by 35% across cloud environments, enforced compliance frameworks (ISO 27001, PCI-DSS, NIST CSF, DORA) across client estates, and ran phishing simulations for 500+ users. I work comfortably across SIEM platforms, EDR tooling, and vulnerability management — and I write Python automation when the tools don't do what I need them to do.
